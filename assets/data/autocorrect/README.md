# Writer autocorrect dictionary

English spelling data is sourced from `wooorm/dictionaries`, package `dictionary-en`, generated from wordlist.aspell.net.

Dictionary and affix files are licensed under MIT AND BSD, as documented by the upstream package:
https://github.com/wooorm/dictionaries/tree/main/dictionaries/en

The Writer uses these files with the MIT-licensed nspell spell-checking engine. MMA-specific vocabulary and fighter names are layered on top at runtime.
